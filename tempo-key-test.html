Tempo and key test

This looks up the same 31 songs in two places: Deezer (what Stanze uses today) and GetSongBPM, which also knows the musical key. It shows where each one has a tempo, whether they agree, and the key.

Tempo and key data provided by GetSongBPM.

1. Your GetSongBPM key

Paste the API key from your GetSongBPM email. It is saved only in this phone's browser, never on the website.

2. Run the test

Press start and wait for it to finish (one to two minutes). Then screenshot the summary and scroll through the list.
