# Lyrica

A personal lyrics teleprompter for your phone. It finds lyrics (and timings) from the free [LRCLIB](https://lrclib.net) library or lets you paste your own, then scrolls and highlights them line by line while keeping the screen awake.

**Open it:** https://jamescleaver1994.github.io/lyrica/

## Put it on your Android home screen
1. Open the link above in Chrome on your phone.
2. Tap the ⋮ menu, then **Add to Home screen** (or **Install app**).
3. Open Lyrica from the new icon. It works offline for songs you have saved.

## How it works
- No server and no account: songs are stored on your phone. Use **Settings → Save backup** now and then.
- Synced songs scroll exactly on time. For other songs, set the song length when editing, or use **⋯ → Tap to time** to create your own timings.
- Chords: type them in square brackets before a word, `[G]First line of my [D]song`, or paste a chord sheet with chords on the line above the words.
- Plain HTML, CSS and JavaScript with no build step, hosted free on GitHub Pages.
